FAQs

  • What part of the order Value can the customer pay using TSH Points?

The customer can pay his entire order value using TSH Points excluding taxes and shipping charges. These points are 100% redeemable for Order Value above INR 750.

Example: If the order value is ₹699, out of which the item cost excluding taxes is ₹750, taxes are ₹50 and shipping charges are ₹149 and if the customer has 750 TSH Points in his account, then the customer needs to pay only ₹199 through other payment options.

  • Can I pay part of my order using TSH Wallet?

Yes. TSH Wallet is just another Payment mode.

  • How long are these points valid?

These points are valid for 7 days from the time of registration post which these points will appear in expired state in the user’s ledger and they cannot be redeemed.

  • What happens when the user Cancels or Returns?

When the user cancels or returns the product, the points get re-credited to the user’s TSH Wallet in active or expired state depending on the original expiry duration of the points while they were credited to the user’s account.

Example: If the points were credited on 1st July and if the expiry was on 7th July and if the user cancels the order on 8th July, then the points will be shown in user’s wallet as expired. Similar rule applies to returns. Note that for returns, the points get credited back to the wallet when the return request is processed and not when the return request is created.

  • Where can I view My TSH Wallet details?

You can view your TSH Wallet under the My Accounts section.
